# Setlist for macOS

[Download the latest stable release](https://github.com/bishopandco/setlist-public/releases/latest).

- **Apple Silicon:** download `Setlist-macOS-arm64.zip`.
- **Intel:** download `Setlist-macOS-x86_64.zip`.
- Requires macOS 13 or newer. Unzip and move `Setlist.app` to Applications.

Setlist checks for updates at startup and every 30 minutes while running. Use **Check for updates…** in the sidebar to check immediately. Installing an update stops the processor and restarts the app; resume analysis from Processing afterwards.

Apps are signed with Developer ID and notarized by Apple. Automatic updates are signed with Sparkle Ed25519. Release candidates use the preview feed; stable builds use the stable feed.

This repository contains downloadable builds and update feeds. Application source is maintained separately.
